# python-object_relational_mapping

This project covers Object-Relational Mapping (ORM) in Python:
connecting to a MySQL database with `MySQLdb`, and mapping database
records to Python objects with `SQLAlchemy`.

## Tasks

### 0. Get all states
`0-select_states.py` connects to a MySQL server and lists all rows
in the `states` table of a given database, sorted by `id` in
ascending order.
