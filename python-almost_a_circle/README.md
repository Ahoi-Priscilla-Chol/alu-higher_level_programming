# Python - Almost a Circle

This project implements a Base, Rectangle, and Square class in Python,
following an OOP structure with private attributes, getters/setters,
inheritance, and full unittest coverage.

## Files

- `models/base.py` - the Base class, managing the id attribute.
- `models/rectangle.py` - the Rectangle class, inheriting from Base.
- `models/square.py` - the Square class, inheriting from Rectangle.
- `tests/` - unittest test cases for all of the above.

## Usage

Run all tests with:

    python3 -m unittest discover tests
